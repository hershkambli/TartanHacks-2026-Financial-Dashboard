# TartanHacks-2026-Financial-Dashboard

Hello!

This smart dashboard helps users control their spending and control their portfolio all in a web application. Users can link their Plaid or Capital One accoutns for seamless access to all the budgeting and portfolio advice provided. The dashboard uses machine learning to give users various investment tips, such as which stocks and bonds to buy in order to maintain their financial wellness.
